## 功能

- **互動動畫**：每個主題以分鏡式 SVG 動畫講解，可逐步播放
- **加強練習**：每主題 5 題選擇題，即時判分並顯示解析
- **三關評量**：基礎／進階／挑戰，題目隨機生成，通關後解鎖下一關
- **完成度排行榜**：依「練習完成主題數 + 通關數」排名，可切換全校／班級
- **顯示大小調整**：四段字級切換，適合投影或手機
- **漫畫風介面**：粗黑框、硬邊陰影、網點底

## 在 GitHub Pages 發布

1. 將所有檔案上傳至 repository
2. Settings → Pages → Source 選擇 `main` 分支根目錄
3. 開啟 `https://<帳號>.github.io/<repo>/` 即為完整平台

`index.html` 即為入口，無需額外設定。
