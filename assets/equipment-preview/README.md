# 星曜騎士裝備試作 v1

2026-09-09，使用內建 image_gen 生成（非付費 API CLI）。

## 生成提示

原創 16-bit 像素裝備圖集，1536×1024、三欄兩列、每格 512×512。上排為開面頭盔、短身胸甲、成對護腿；下排為成對戰靴、向上的直立巨劍、披風。銀鋼、金邊、深藍布料、青綠星形寶石；深色像素描邊、三階明暗、少量白色高光。無角色、文字、格線、陰影與光暈；各部位不重疊，裝備不透明，適合大頭短腿正面紙娃娃。

第二次精準編輯提示：保留六件裝備顏色、外形與位置，移除背景及光暈，保留裝備黑色描邊；包含頭盔開口、褲管與鞋子之間的空白。巨劍縮小 8%、向下移動 20px，避免跨到上排格子。

## 實際結果與限制

- 工具仍輸出棋盤背景而非真正 alpha；試作載入時只對「連接到圖集邊緣的中性明亮背景」建立透明遮罩，避免破壞黑色描邊內的銀色高光。原圖保留。
- 透明遮罩及六個 sprite 邊界只計算一次；各角色共用同一張已解碼圖集，不在動畫每格重新解析像素。
- 這是獨立美術驗證頁，尚未替換正式背包、商店或多人戰場。
- 校正以 100×122、viewBox `0 -20 100 122` 為基準；素體中線 50、腳底 92。胸甲與護腿依素體白衣／藍褲像素估算，仍允許手動微調。
- 未執行 30 台實機多人連線測試，不能由本機瀏覽器測試推論所有教室裝置效能。
